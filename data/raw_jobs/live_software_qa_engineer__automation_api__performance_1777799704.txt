Job Title: Software QA Engineer – Automation, API & Performance
Company: AI Technologies LLC.

Description:
Responsibilities Develop comprehensive test plans and detailed test cases based on functional and technical specifications. Execute functional tests to verify build meets specified requirements. Test the integration points between systems (both internal/external) ensuring seamless data flow and integration. Perform regression testing to ensure that new code changes or updates do not negatively impact existing functionality. Evaluate the performance of applications under various load conditions. Identify, document and track defects using a defect tracking system. Analyze defects to determine the root cause and verify that they are resolved before release. Collaborate with developers to resolve defects and ensure timely fixes. Contribute to the development and maintenance of test automation frameworks and scripts. Implementing the API logic and functionality using appropriate programming languages and framework.
